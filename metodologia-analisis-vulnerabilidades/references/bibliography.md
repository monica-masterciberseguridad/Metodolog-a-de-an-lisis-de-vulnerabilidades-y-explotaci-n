# Bibliografía y recursos técnicos

1. NIST, *SP 800-115: Technical Guide to Information Security Testing and Assessment* (2008). Guía para planificar y realizar pruebas técnicas, analizar hallazgos y definir mitigaciones.  
   https://csrc.nist.gov/pubs/sp/800/115/final

2. MITRE, *CWE-787: Out-of-bounds Write*. Definición, consecuencias y mitigaciones de escrituras fuera de límites.  
   https://cwe.mitre.org/data/definitions/787.html

3. CERT-EU, *Security Advisory 2021-007: UPDATE: Sudo Heap-based Buffer Overflow* (2 febrero 2021).  
   https://cert.europa.eu/publications/security-advisories/2021-007/

4. Debian Security Tracker, *CVE-2021-3156*. Descripción y seguimiento de paquetes afectados y corregidos.  
   https://security-tracker.debian.org/tracker/CVE-2021-3156

5. AFL++, *Documentation*. Guías de instrumentación, preparación de corpus, fuzzing y triage.  
   https://aflplus.plus/docs/

6. AFL++, *Fuzzing in Depth*. Flujo de trabajo y consideraciones prácticas.  
   https://aflplus.plus/docs/fuzzing_in_depth/

7. OWASP, *Web Security Testing Guide*. Referencia metodológica complementaria para pruebas de aplicaciones y servicios web.  
   https://owasp.org/www-project-web-security-testing-guide/
